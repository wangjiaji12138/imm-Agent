# 独立评测报告模板

**状态：PLANNED，任务 40 尚未运行；本文件不是验收通过报告。** [任务卡](tasks/phase-05-release.md#task-40)

实现时由 evaluate_answers 输出带运行 ID 的报告到 artifacts/，本文件作为入口或人工审查摘要。不能覆盖旧报告。

| 字段 | 待记录内容 |
| --- | --- |
| 运行标识 | 时间、代码提交、数据版本、题集划分 |
| 配置 | Embedding、生成模型、提示词、切分和检索配置 |
| 检索 | 每题 Top 5、Recall@5、撤回资料命中率 |
| 回答 | 引用可解析率、无来源关键结论、证据不足行为率 |
| 系统 | 成功率、P95、token 用量、估算单次成本 |
| 审查 | 逐题错误、证据核对、原因、接受/修复决定 |

最低门槛见任务 40，不能以题目格式校验 ready=true 替代模型质量评测。
