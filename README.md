这是一个免疫疗法科普Agent

初步想法：
## 前身：癌症免疫疗法的科普网页
利用爬虫技术搜集了多种免疫疗法的信息，存储在MySQL数据库中，每一条免疫疗法的数据按照“免疫疗法名-癌症-正文介绍”简单的实现了库的搭建。
搭建了一个搜索网页，可以利用搜索功能实现“输入免疫疗法/癌症”，显示他们对应的匹配页面，但页面也就只是展示了爬取下来的免疫疗法的介绍。

## 预期功能：Imm-Agent
意图还是宣传癌症免疫疗法的知识，但是需要自己搭建Agent、或者是微调大模型，注入癌症免疫疗法的知识。
